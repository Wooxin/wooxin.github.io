> 七日杀通过 SteamCMD 下载，App ID `294420`。Unity 引擎，对单核性能要求高。

七日杀的特色在于——世界是完全可破坏的。你挖的每块石头、砍的每棵树、盖的每堵墙都会永久改变世界。这意味着服务器的存档会随着时间越来越大，而且 CPU 负载和你改变了多少方块直接相关。玩了几周的老存档比新存档吃资源多很多。

建议定期在游戏里清理地面上的掉落物（背包、石头、木头碎片），这些东西每个都是独立计算的对象，多了会拖慢服务器。

## 配置 serverconfig.xml

第一次运行后，`serverconfig.xml` 会生成在服务端根目录下。关键配置：

```xml
<ServerSettings>
  <!-- 服务器名称（显示在列表里） -->
  <property name="ServerName" value="我的七日杀服"/>

  <!-- 世界名称（存档文件夹的名字） -->
  <property name="GameWorld" value="Navezgane"/>

  <!-- 世界名称（游戏名） -->
  <property name="GameName" value="MyGame"/>

  <!-- 难度（0-5，越大越难） -->
  <property name="GameDifficulty" value="2"/>

  <!-- 一天的长度（分钟，默认 60） -->
  <property name="DayNightLength" value="60"/>

  <!-- 白天时长（小时，默认 18） -->
  <property name="DayLightLength" value="18"/>

  <!-- 最大玩家 -->
  <property name="ServerMaxPlayerCount" value="8"/>

  <!-- 密码 -->
  <property name="ServerPassword" value="secret"/>

  <!-- 端口 -->
  <property name="ServerPort" value="26900"/>

  <!-- PVP 模式 -->
  <property name="Player Killing" value="2"/>

  <!-- 僵尸在血月时的数量（默认 8，人多调到 16+） -->
  <property name="BloodMoonEnemyCount" value="8"/>
</ServerSettings>
```

## 端口

七日杀需要三个端口（26900-26902）：

```bash
sudo ufw allow 26900:26902/udp
sudo ufw allow 26900/tcp
```

## systemd 服务

```bash
sudo cat > /etc/systemd/system/sdtd.service << 'EOF'
[Unit]
Description=7 Days to Die Server
After=network.target

[Service]
User=root
WorkingDirectory=/root/sdtd/server
ExecStart=/root/sdtd/server/startserver.sh -configfile=serverconfig.xml
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now sdtd
```

## 备份世界

存档在服务端的 `Saves/` 目录下，包含世界名文件夹：

```bash
tar -czf "sdtd-backup-$(date +%Y%m%d).tar.gz" Saves/
```

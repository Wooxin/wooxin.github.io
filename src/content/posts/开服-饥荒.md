> 饥荒联机版（Don't Starve Together）需要 SteamCMD 下载，App ID `343050`。DST 的特殊之处在于它必须同时跑**两个进程**——一个管地面（Master），一个管洞穴（Caves），互相对接。

如果你只开地面不开洞穴，地表世界可以正常玩，但洞穴内容（远古科技、地下蘑菇林）完全无法访问。所以正经开服一定是双进程。

<div class="distro-code" id="dst-ubuntu">

```bash
sudo dpkg --add-architecture i386
sudo apt update && sudo apt install -y steamcmd lib32gcc-s1 screen

mkdir -p ~/dst && cd ~/dst
steamcmd +force_install_dir ./server +login anonymous +app_update 343050 validate +quit

# 启动 Master（地面）——在 screen 会话里跑
screen -S dst-master
cd ~/dst/server/bin
./dontstarve_dedicated_server_nullrenderer -cluster MyDediServer -shard Master

# 按下 Ctrl+A 再按 D 分离，然后启动 Caves（洞穴）
screen -S dst-caves
./dontstarve_dedicated_server_nullrenderer -cluster MyDediServer -shard Caves
```

## Token 获取（必须）

没有 Token 服务器运行不了。获取方法：
1. 打开饥荒联机版游戏
2. 主菜单 → 账号信息 → 前往账号网站
3. 在 Klei 网站上生成服务器 Token
4. 把 Token 写入文件：

```bash
mkdir -p ~/.klei/DoNotStarveTogether/MyDediServer
echo "你的Token字符串" > ~/.klei/DoNotStarveTogether/MyDediServer/cluster_token.txt
```

## 配置 cluster.ini

在 `~/.klei/DoNotStarveTogether/MyDediServer/` 下创建 `cluster.ini`：

```ini
[GAMEPLAY]
game_mode = survival          # 生存模式（endless=无尽，wilderness=荒野）
max_players = 8
pvp = false
pause_when_empty = false      # 没人也继续跑（重要！）

[NETWORK]
cluster_name = 我的饥荒服
cluster_description = 欢迎来玩
cluster_password = secret     # 不设密码=公开服

[MISC]
max_snapshots = 6             # 回档次数
```

## 端口

```bash
sudo ufw allow 10999:11000/udp
```

## systemd 两个服务

```bash
# Master 服务
sudo cat > /etc/systemd/system/dst-master.service << 'EOF'
[Unit]
Description=DST Master Server
After=network.target

[Service]
User=root
WorkingDirectory=/root/dst/server/bin
ExecStart=/root/dst/server/bin/dontstarve_dedicated_server_nullrenderer -cluster MyDediServer -shard Master
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF

# Caves 服务（同理，把 -shard Master 改成 -shard Caves）
```

启动：
```bash
sudo systemctl enable --now dst-master dst-caves
```

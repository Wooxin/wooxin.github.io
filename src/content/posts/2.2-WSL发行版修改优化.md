## 包管理器
一个真正好用的Linux系统是离不开一个好用的包管理器的, 这里推荐apk
### 安装部署APK
```shell
# 下载apk
wget https://dl-cdn.alpinelinux.org/alpine/v3.22/main/x86_64/apk-tools-static-2.14.9-r3.apk
# 解压
tar -zxvf apk-tools-static-2.14.9-r3.apk sbin/apk.static
# 放入bin
mv sbin/apk.static /usr/bin/apk
# 初始化apk包管理器
mkdir -p /etc/apk /lib/apk/db
echo "https://dl-cdn.alpinelinux.org/alpine/v3.22/main" > /etc/apk/repositories
# 创建软连接
ln -s /lib/apk /usr/lib/apk
# 查看版本号
apk --version
```

```shell
# 软链接方法
mkdir -p /opt/apk/conf
mv ./apk.static /opt/apk/
touch /opt/apk/conf/repositories
mkdir /opt/apk/conf/db
ln -sf /opt/apk/apk.static /usr/bin/apk
ln -sf /opt/apk/conf/ /etc/apk
ln -sf /opt/apk/conf/ /lib/apk
mkdir /usr/lib/
ln -sf /opt/apk/conf/ /usr/lib/apk
apk --version
chmod +x /opt/apk/apk.static
```

### Dropbear
Dropbear相比openssh更加小巧高效
```shell
创建软链接
ln -s /opt/dropbear/dropbearmulti /usr/bin/dropbear
# 然后直接启动 dropbear
dropbear
```

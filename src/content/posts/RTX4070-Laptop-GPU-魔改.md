## 为什么要折腾笔记本显卡？

笔记本 GPU 和台式机同型号之间最大的鸿沟，不是核心规模，而是**功耗墙**。以 RTX 4070 Laptop 为例，NVIDIA 把 TGP 范围放得极宽：最低 35W，最高 140W。同一颗 AD106 核心，115W 和 140W 之间的性能差距可以达到 15%~20%。

我这台本子的 4070 出厂锁在 115W，打游戏还好，跑 CUDA 编译和 AI 推理的时候明显感觉差一口气。于是动了念头——能不能把它刷到 140W？

> **警告：以下操作涉及硬件改装和固件刷写，刷坏 VBIOS 会导致显卡无法点亮甚至主板损坏。请务必备份原始 VBIOS 后再动手。**

---

## 第一步：摸清底细

动手之前，先把硬件信息查清楚：

### 确认 GPU 核心代号与 Device ID

```bash
# Windows 下用 GPU-Z 或 nvidia-smi
nvidia-smi --query-gpu=gpu_name,device_id,pcie.link.gen.max --format=csv
```

我的输出：
```
NVIDIA GeForce RTX 4070 Laptop GPU, 10DE 2820, 4
```

Device ID `10DE 2820` 是关键——跨刷 VBIOS 必须**同一 Device ID**，不同 ID 大概率黑屏。

### 确认显存厂商

```bash
# GPU-Z → Advanced → Memory → GDDR6X Vendor
```

我的是**三星 GDDR6X**。VBIOS 必须匹配显存品牌，三星和镁光的时序不同，混刷会花屏。

### 确认 PCB 板型和供电设计

拆机拍照。重点关注：

- **供电相数**：我这块是 6+2 相（核心 6 相 + 显存 2 相）
- **MOSFET 型号**：DrMOS 还是分立 MOS，直接决定能不能扛住大电流
- **散热模组**：热管数量、鳍片面积、风扇规格

140W VBIOS 要求 PCB 能稳定输出 140W+ 的持续功耗。如果供电缩水，刷 140W VBIOS 之后大概率触发 VRM 过热保护，降频甚至断电。

---

## 第二步：备份原始 VBIOS

这是最不能省的一步。刷坏了可以盲刷恢复，前提是你有备份。

### 用 GPU-Z 备份（推荐）

GPU-Z → BIOS Version 旁边有个保存图标，点击导出 `.rom` 文件。存两份，一份本地，一份云端。

### 用 nvflash 备份（备选）

```bash
nvflash --save 4070_backup.rom
```

备份完**验证一下**：用 `nvflash --compare` 把备份和当前 VBIOS 做比对，确保备份完整。

---

## 第三步：寻找合适的 VBIOS

这是整个魔改最耗时间的环节。去 [TechPowerUp VGA BIOS Database](https://www.techpowerup.com/vgabios/) 筛选条件：

1. **GPU**：RTX 4070 Laptop (AD106)
2. **Device ID**：`10DE 2820`
3. **显存**：Samsung GDDR6X
4. **TGP**：140W
5. **来源**：大厂笔记本（联想、ROG、外星人），这些的 VBIOS 相对规范和稳定

筛出来大概 5~8 个候选。逐个对比：

| VBIOS 来源 | TGP | 核心频率 Boost | 显存频率 | 风扇策略 |
|---|---|---|---|---|
| 原厂 115W | 115W | 1695 MHz | 2000 MHz | 保守 |
| 外星人 m18 | 140W | 1980 MHz | 2000 MHz | 激进 |
| ROG Strix | 140W | 2070 MHz | 2000 MHz | 偏激进 |
| 联想 Legion | 140W | 1965 MHz | 2000 MHz | 平衡 |

> 选 VBIOS 的黄金法则：**同 Device ID + 同显存 + 同供电相数 + 散热能跟上**。优先选带 Dynamic Boost 的版本，这样在混合负载下可以智能分配 CPU/GPU 功耗。

我最终选了联想 Legion 的 140W VBIOS，风扇策略相对平衡，不会起飞。

---

## 第四步：刷写 VBIOS

### 工具准备

- **nvflash 带保护绕过版本**（普通版不允许跨型号刷写）
- **一个 U 盘 PE 系统**，防止刷黑后无法进系统

### 刷写命令

```bash
# 先检测是否支持
nvflash --protectoff

# 刷写
nvflash -6 legion_4070_140w.rom

# 刷完后重启
shutdown /r /t 0
```

`-6` 参数跳过 Board ID 和 Subsystem ID 校验，是跨刷的关键。

### 刷完第一件事

进系统后立刻跑 **GPU-Z** 确认 TGP 变成了 140W。再跑一轮 **FurMark + HWiNFO** 双开，观察：

- **GPU 功耗**能否稳定跑到 140W
- **GPU 热点温度**不超过 90℃
- **显存结温**不超过 100℃
- **VRM 温度**有无异常飙升

我的结果：功耗稳在 138~142W，核心温度 82℃，热点 88℃，在安全范围内。

---

## 第五步：电压曲线优化

TGP 上去了，下一步是**降压超频（Undervolt + OC）**。AD106 核心在 140W 下实际瓶颈是频率上限而非功耗，降压能腾出功耗空间让核心跑到更高频率。

### MSI Afterburner 曲线设置

```
1. 打开 Afterburner → Ctrl+F 进入电压/频率曲线
2. 找到 0.925V 这个点，锁定
3. 从 0.925V 开始，所有后续点按住 Shift 选中 → 回车 → 输入偏移值
4. 核心 +180MHz，显存 +800MHz
5. Apply → 跑 Time Spy 稳定性测试
```

降压到 0.925V 的逻辑：原厂在 1.0~1.05V 区间效率下降严重，多出来的电压带来的发热远大于频率收益。把电压压到 0.925V 的甜点，同功耗下核心能多跑 100~150MHz。

### 稳定性验证

跑 **3DMark Time Spy Stress Test**（20 轮循环），通过标准：

- 帧率稳定度 ≥ 97%
- 全程无花屏、无闪屏、无驱动重置
- 最高温度不超过 90℃

---

## 第六步：散热补强

140W VBIOS 跑通之后，热点温度从原来的 78℃ 升到了 88℃。离 90℃ 安全线太近，尤其是夏天。

### 换了相变硅脂（PTM7950）

传统硅脂在笔记本高温环境下 3~6 个月就干裂了，导热效率断崖下跌。**霍尼韦尔 PTM7950 相变片**是笔记本的神——55℃ 以上从固态变液态填满缝隙，降温后恢复固态不流失。

贴的时候注意：
- 核心面积不大，一小片 10mm×10mm 足够
- **不要手撕**，放冰箱冻 5 分钟，用刀片一次性切下，直接覆盖核心
- 不追求厚涂，相变材料越薄越好

### 供电散热垫更换

原厂的导热垫普遍是 6W/mK 的普通硅脂垫。我把 VRM 和显存的导热垫全换成了 **莱尔德 HD90000（7.5W/mK）**，供电温度从 85℃ 降到了 72℃，效果明显。

厚度一定要卡准——用游标卡尺量好原垫厚度再买，厚了会把核心顶起来导致散热悬空，薄了接触不到等于白换。

## 跑分对比

| 测试项目 | 原厂 115W | 刷 140W + 降压超频 | 提升 |
|---|---|---|---|
| Time Spy Graphics | 11400 | 13280 | +16.5% |
| Fire Strike Graphics | 28600 | 33000 | +15.4% |
| Port Royal | 6850 | 7900 | +15.3% |
| FurMark 1080p | 112 FPS | 136 FPS | +21.4% |
| Blender BMW | 46s | 38s | -17.4% |
| TensorRT 推理 (Whisper) | 180ms | 152ms | -15.6% |

核心+显存双超的情况下，光栅和光追性能都稳定提升 15~20%，CUDA 生产力提升 17%，已经无限接近桌面端 RTX 4060 Ti 水平。

## 踩过的坑

1. **镁光显存刷了三星 VBIOS**：花屏，进系统 3 秒就花。得盲刷恢复。教训：**一定确认显存厂商**。

2. **忘了关 Secure Boot**：nvflash 保护关不掉，刷写失败。进 BIOS 关 Secure Boot → 刷 → 再开回来。

3. **Afterburner 解锁电压不完整**：默认设置没有解锁电压控制。进 Settings → General → 勾选 "Unlock voltage control" 和 "Unlock voltage monitoring"，选 "Third party" 模式。

4. **Dynamic Boost 冲突**：有些 140W VBIOS 的 DB 策略过于激进，导致 CPU 被挤到 15W 以下，游戏反而掉帧。解决方法是装 NVIDIA Platform Controllers and Framework，在电源选项里设置 "Maximum processor state" 限制 DB 幅度。

5. **热管偏位**：换了导热垫之后厚度不对，热管没压到核心，开机 2 分钟后 GPU 温度飙到 102℃ 自动关机。重新拆机、重新测量、重新贴。

---

## 小结

RTX 4070 Laptop 魔改的本质是**解锁 NVIDIA 没有给你的那 25W**。核心硬件（AD106、显存控制器、供电）在出厂时就能扛 140W，只是厂商为了区分产品线或者散热/保修考虑，用 VBIOS 锁了一部分性能。

整个流程总结：
1. 摸清硬件底细（Device ID、显存、供电）
2. 备份 VBIOS
3. 找匹配的 140W VBIOS
4. 刷写 + 验证
5. 降压超频榨干甜点效能
6. 散热补强保长期稳定

折腾下来最大的感悟：笔记本显卡的瓶颈从来不是硬件本身，而是功耗分配和散热设计。花了两个晚上折腾，跑分涨了接近 17%，值了。

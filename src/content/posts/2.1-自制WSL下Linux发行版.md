## 准备工作
```shell
# 创建一个目录用于存放工作文件
mkdir -p mymini-linux/{rootfs,kernel}
cd ./mymini-linux
```

## 编译BusyBox
使用BusyBox可以一站式使用Linux基础命令, 从而取代GNU工具链
与普通Linux发行版不同的是, 在这里你不需要构建内核, 只需要构建属于你的busyBox即可

```shell

# 下载解压, 自行寻找最新版
wget https://busybox.net/downloads/busybox-1.37.0.tar.bz2
tar -xf busybox-1.37.0.tar.bz2

# 编译
cd busybox-1.36.1
make defconfig  # 默认配置
make menuconfig  # 自定义：启用 init、sh 等，禁用多余（如 httpd, td）
# 如果你是archlinux一定会遇到ncurses报错, 通过修改./scripts/kconfig/lxdialog/check-lxdialog.sh中的main() {} 为int main() {}来解决
make -j$(nproc)
make install CONFIG_PREFIX=../rootfs  # 安装到 rootfs
cd ..
rm -fr busybox-1.37.0*
```

## 构建根文件系统 (rootfs)
### 创建必要的目录和文件
```shell
cd rootfs
mkdir -p bin sbin etc/init.d dev proc sys tmp var lib
# 创建设备节点
sudo mknod dev/console c 5 1
sudo mknod dev/null c 1 3
sudo mknod dev/zero c 1 5
# 创建 init 脚本（/etc/init.d/rcS 或直接用 BusyBox init）
echo '#!/bin/sh' > etc/init.d/rcS
echo 'mount -t proc none /proc' >> etc/init.d/rcS
echo 'mount -t sysfs none /sys' >> etc/init.d/rcS
echo 'mount -t tmpfs none /tmp' >> etc/init.d/rcS
echo '/sbin/mdev -s' >> etc/init.d/rcS  # 动态设备
chmod +x etc/init.d/rcS
ln -s bin/busybox init  # 用 BusyBox 作为 init
cd ..
```

## 打包并引入wsl
```shell
# 打包你的rootfs
tar --acls --xattrs -C ./rootfs/ -cvf ../wox-minimal.tar .

# 传输到windows
cp -fr ../wsl2-minimal-wox.tar /mnt/d/Download/
# 或 通过windows拉取
scp -r root@192.168.158.166:/root/wox-minimal.tar D:\Download\

# 引入到你的wsl
wsl --import woxlinux "D:\Work\VM\WSL\WoxLinux" "D:\Work\VM\WSL\WoxLinux\wox-minimal.tar" --version 2

# 启动!!!
wsl -d woxlinux
```

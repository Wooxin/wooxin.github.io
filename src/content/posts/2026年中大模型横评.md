这半年模型更新速度实在太快了, 不记下来真的会忘. 这篇是我自己用的选模型备忘录, 顺带分享出来.

> 口径说明: 这里列的模型是**主流可用/有代表性的**, 不可能穷尽每个小版本和私有内测模型. 排名不是单一 benchmark, 而是综合: 通用能力、编程、推理、长上下文、多模态、Agent/工具调用、价格/速度、可部署性、中文体验.

---

## 一句话结论

如果只想选一个最稳的: **GPT-5.5 Thinking / Pro**.

如果主要写代码、做复杂项目: **Claude Opus 4.7/4.8、GPT-5.5、Gemini 3.1 Pro、Kimi K2.6、GLM-5.1**.

如果要长上下文、文档/仓库/多模态: **Gemini 3.1 Pro、MiniMax M3/M1、Kimi K2.6、Llama 4 Scout**.

如果要性价比、开源/本地/可控: **Qwen3 系列、DeepSeek V3/R1/V4 系、Kimi K2.5/2.6、MiniMax M1/M3、GLM-5/5.1、Llama 4、Mistral Medium/Magistral**.

如果要联网、实时信息、X 生态: **Grok 4**.

如果要中文综合体验: **Qwen、Kimi、DeepSeek、GLM、MiniMax** 往往比海外模型更顺手.

## 第一梯队: 闭源旗舰模型

| 模型 | 综合定位 | 最适合干什么 | 不太适合什么 | 推荐指数 |
|---|---|---|---|---|
| GPT-5.5 Thinking / Pro | 最均衡的通用旗舰 | 复杂知识工作、代码、研究、数据分析、文档、表格、工具调用 | 预算极敏感、本地部署 | ★★★★★ |
| Claude Opus 4.7 / 4.8 | 编程与长任务强者 | 大项目编程、重构、Agent、长时间任务规划、严谨写作 | 价格敏感、需要超大生态插件 | ★★★★★ |
| Gemini 3.1 Pro | 多模态与长上下文强者 | 读 PDF/视频/图片/代码仓库、长文档分析、Google 生态、复杂推理 | 中文语感有时不如国产模型 | ★★★★★ |
| Grok 4 / Grok Build 0.1 | 实时信息与 X 生态 | 实时搜索、热点信息、轻量代码、社交趋势分析 | 企业稳健性、安全边界、严肃文档 | ★★★★☆ |
| Claude Sonnet 4.6/4.7 | 高性价比 Claude | 日常代码、编辑、项目助手、Agent | 极限复杂任务不如 Opus | ★★★★☆ |
| GPT-5.5 Instant | 快速通用默认模型 | 日常问答、写作、翻译、轻量代码、快速总结 | 超复杂推理/大型项目 | ★★★★☆ |

### 选择建议

- **你只买一个会员/只接一个 API**: 优先 GPT-5.5.
- **你主要让 AI 改项目代码**: 优先 Claude Opus / Sonnet, 其次 GPT-5.5、Gemini 3.1 Pro.
- **你经常喂超长文档、视频、PDF、整个代码仓库**: 优先 Gemini 3.1 Pro.
- **你需要实时热点和 X 数据**: Grok 4 有独特优势.

### 选择建议

- **本地跑 / Ollama / 私有部署**: Qwen、DeepSeek、Llama、MiniMax、Mistral.
- **中文项目、中文资料、中文问答**: Qwen、Kimi、DeepSeek、GLM.
- **低成本写代码**: DeepSeek、Qwen、Kimi、GLM.
- **超长上下文**: Gemini、MiniMax、Kimi、Llama 4 Scout.

## 按我的使用场景推荐

我经常折腾 Windows + Linux + Ollama + Claude Code/Cline/Hermes 这类 AI 编程环境, 所以建议按下面组合:

### 日常主力

- **ChatGPT / GPT-5.5 Thinking**: 做总控、问复杂问题、写方案、整理文档.
- **Claude Opus / Sonnet**: 专门干复杂项目代码、重构、代码审查.
- **Gemini 3.1 Pro**: 专门读长 PDF、长网页、图片、视频、整个代码仓库.

### 本地编程模型

- **qwen3-coder / qwen3 系列**: 本地写代码首选.
- **deepseek-r1 / deepseek-coder / deepseek-v3 系**: 推理、代码、调试.
- **mistral / magistral**: 轻量多语言和推理备用.
- **llama4**: 英文、多模态、本地生态备用.

### Agent 工具搭配

| 工具 | 推荐模型 |
|---|---|
| Claude Code / CCR | Claude、GPT-5.5、GLM、DeepSeek、Qwen |
| Cline / Roo Code | Claude Sonnet/Opus、GPT-5.5、DeepSeek、Qwen、GLM |
| OpenHands | Claude Opus、GPT-5.5、Gemini、Kimi、GLM |
| Hermes / 自进化 Agent | Kimi、Qwen、DeepSeek、GLM、本地向量库 |
| 本地 Ollama | Qwen、DeepSeek、Llama、Mistral、MiniMax 可用版本 |

## 最终结论

### 闭源旗舰三巨头

1. **GPT-5.5**: 最均衡, 适合大多数人当主力.
2. **Claude Opus 4.7/4.8**: 最适合复杂编程和长任务 Agent.
3. **Gemini 3.1 Pro**: 最适合长上下文和多模态资料分析.

### 国产/开源四强

1. **Qwen**: 中文 + 开源 + 本地部署最稳.
2. **DeepSeek**: 推理 + 性价比最突出.
3. **Kimi**: 长上下文 + Agent + 代码很强.
4. **GLM / MiniMax**: Agentic coding 和长上下文很值得关注.

### 我最推荐的组合

- **一个闭源主力**: GPT-5.5 或 Claude Opus.
- **一个长上下文工具**: Gemini 3.1 Pro.
- **一个本地模型**: Qwen3 Coder 或 DeepSeek.
- **一个国产 Agent 模型**: Kimi K2.6 或 GLM-5.1.

- **内容驱动架构**：采用 Astro Content Collections (`src/content/config.ts`) 管理 Markdown 文章，通过 Zod 定义严格的元数据 Schema（标题、日期、分类等）。
- **页面路由层**：`src/pages` 实现动态路由（如 `[slug].astro`）与静态归档页，利用 `getStaticPaths` 在构建期预渲染所有文章。
- **布局与组件层**：`BaseLayout.astro` 作为全局容器，封装了导航栏、侧边栏、SEO 标签及主题切换逻辑；`src/utils/posts.ts` 提供统一的日期处理、Slug 生成及文件状态检测工具。
- **自动化增强层**：通过 `scripts/summarize.mjs` 在构建前调用 LLM API 生成文章摘要并持久化至 JSON，`new-post.mjs` 简化创作流程。
- **静态资源层**：`public/` 存放 CSS、验证文件及客户端脚本，`src/assets` 管理构建期优化的图片资源。
